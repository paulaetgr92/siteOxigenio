# Site conceito — Lojas Oxigênio

Projeto original inspirado apenas na linguagem editorial e na estrutura visual da referência enviada. O CSS e o JavaScript foram escritos do zero.

## Como visualizar
Abra `index.html` no navegador ou rode um servidor local:

```bash
python3 -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Trocar o vídeo principal
Substitua:

`assets/video/hero-oxigenio.mp4`

Mantenha o mesmo nome ou altere o caminho no `index.html`. Recomendação: vídeo horizontal 1920 × 1080 px, MP4/H.264, 8–15 segundos, sem áudio, até 8 MB.
